To propose a new dataset:

  1. Open a submission issue
    1. Go to the repository’s Issues tab
    2. Click New issue
    3. Select the Add Dataset Entry to TopDat-ED issue template
  2. Fill out the issue form
    1. Provide the dataset title, year, and URL
    2. Select the appropriate domain, representation, realism, and scale
    3. Submit the issue
Collaborators welcome to new datasets submissions and keep the directory fresh 😊
