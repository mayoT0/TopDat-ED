# TopDat-ED Electrical Dataset Directory

Explore electrical topology datasets using a searchable and filterable directory at [TopDat-ED](https://mayot0.github.io/TopDat-ED/):

- Multi-select navigation filters
- Search-by-title functionality

---

# Features

## Interactive Filtering

Datasets can be filtered using multi-select button filters:

- Domain
- Representation
- Realism
- Scale
---

## Search

Search the catalog by title using the search bar.

Example searches:

- `grid`
- `netlist`
- `pcb`

# Update Requests

To propose a new dataset:

1. **Open a submission issue**
   1. Go to the repository’s **Issues** tab
   2. Click **New issue**
   3. Select the **Add dataset** issue template

2. **Fill out the issue form**
   1. Enter the dataset title, year, and URL
   2. Choose the appropriate domain, representation, realism, and scale
   3. Submit the issue
